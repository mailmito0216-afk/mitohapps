基本設定 / Basic setup

  1. Pixel標準の着信音を「なし」に設定します。
  2. Dual RingtoneでSIM1とSIM2のMP3ファイルを選択します。
  3. 必要な権限を許可し、アプリをバックグラウンドで動作させます。
  1. Set the default Pixel ringtone to “None.”
  2. Select MP3 files for SIM1 and SIM2 in Dual Ringtone.
  3. Grant the required permissions and allow the App to run in the background.
