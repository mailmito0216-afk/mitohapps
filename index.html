Made for Google Pixel 9a

デュアルSIMの着信音を、
SIMごとに鳴り分け。

Dual Ringtoneは、Google Pixel 9aでSIM1とSIM2に別々のMP3着信音を設定するためのAndroidアプリです。 会社用SIMと個人用SIMを、電話が鳴った瞬間に聞き分けられます。

クローズドテストに参加する 詳しく見る

対応端末：Google Pixel 9a。現在、Google Playクローズドテスターを募集しています。

Google PixelのデュアルSIM着信音問題を解決

Pixel 9aで2つのSIMを使っていても、標準機能ではSIMごとに別の着信音を設定できません。 Dual Ringtoneは、着信したSIMを判定し、あらかじめ選んだMP3をSIM別に再生します。

SIM1とSIM2を聞き分け

会社用と個人用など、どちらの番号への着信かを音だけで判断できます。

好きなMP3を選択

端末内のMP3ファイルを、SIM1用・SIM2用として個別に選択できます。

Pixel 9a専用設計

実機のGoogle Pixel 9aで開発・検証しています。対応範囲を明確にした小さなアプリです。

使い方

  1. Pixel標準の着信音を「マイサウンド → なし」に設定します。
  2. Dual RingtoneでSIM1用のMP3を選びます。
  3. SIM2用のMP3を選びます。
  4. アプリが着信を監視し、着信したSIMに対応する音を再生します。

よくある質問

Pixel 9a以外でも使えますか？

現在の正式な対応・検証対象はGoogle Pixel 9aのみです。

個人情報を収集しますか？

アプリは広告、Firebase、Crashlytics、アクセス解析を使用せず、個人情報を収集しません。

なぜ標準着信音を「なし」にする必要がありますか？

Pixel標準の着信音とDual Ringtoneの音が同時に鳴るのを防ぐためです。
