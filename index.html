Pixel 9aで「SIMごとに着信音を変えたい」

デュアルSIMを使っていると、会社用の番号なのか、個人用の番号なのかを、画面を見る前に知りたいことがあります。

しかしPixel 9aの標準設定には、SIM1とSIM2へ別々の着信音を割り当てる機能がありません。

Dual Ringtoneは、その一点をシンプルに解決するために作りました。

Dual Ringtoneでできること

SIM1 / SIM2を判定

どちらのSIMに着信したかを判定し、そのSIMに設定した音を再生します。

好きなMP3を個別指定

SIM1用、SIM2用として端末内のMP3ファイルをそれぞれ選択できます。

Pixel 9a専用設計

対応範囲を広げすぎず、実機Pixel 9aを正式な開発・検証対象としています。

設定方法

  1. Pixel標準の着信音を「マイサウンド → なし」に設定します。
  2. Dual RingtoneでSIM1用のMP3を選択します。
  3. SIM2用に別のMP3を選択します。
  4. アプリが着信を監視し、着信したSIMに対応するMP3を再生します。

よくある質問

Pixel 9a以外でも使えますか？

現在の正式な対応・検証対象はGoogle Pixel 9aです。

SIM1とSIM2に違う曲を設定できますか？

はい。それぞれに別のMP3ファイルを選択できます。

なぜPixel標準着信音を「なし」にするのですか？

標準着信音とDual Ringtoneの音が二重に鳴るのを防ぐためです。

個人情報を収集しますか？

アプリ本体は広告、Firebase、Crashlytics、アクセス解析を使用せず、個人情報を収集しません。
