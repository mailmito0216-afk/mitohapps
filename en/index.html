Want a different ringtone for each SIM on Google Pixel 9a?

With dual SIM, it is useful to know whether a work number or personal number is ringing before checking the screen.

Google Pixel 9a does not provide a standard setting that assigns a separate ringtone to SIM 1 and SIM 2.

Dual Ringtone was built specifically to solve this Pixel dual SIM ringtone problem.

What Dual Ringtone does

Detects SIM 1 or SIM 2

The app identifies which SIM receives the incoming call and plays the ringtone assigned to that SIM.

Separate MP3 ringtone for each SIM

Select one MP3 for SIM 1 and another MP3 for SIM 2.

Built and tested for Pixel 9a

Google Pixel 9a is the defined development and test device.

How to set different ringtones for SIM 1 and SIM 2

  1. Set the standard Pixel ringtone to “My Sounds → None.”
  2. Select an MP3 ringtone for SIM 1 in Dual Ringtone.
  3. Select a different MP3 ringtone for SIM 2.
  4. The app plays the MP3 assigned to the SIM receiving the incoming call.

Google Pixel 9a dual SIM ringtone FAQ

Can I set a different ringtone for each SIM on Google Pixel 9a?

Yes. Dual Ringtone lets you select a different MP3 ringtone for SIM 1 and SIM 2.

Does Dual Ringtone work on phones other than Pixel 9a?

Google Pixel 9a is currently the officially supported and tested device.

Why must the standard Pixel ringtone be set to None?

This prevents the standard Pixel ringtone and the Dual Ringtone MP3 from playing at the same time.
